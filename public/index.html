Security Architecture

This system highlights several core web security principles:

  • Zero-Trust Keys: Your Private Key is generated and processed in-memory client-side. The backend never sees it.
  • Blockchain Immutability: The document hash is stored as a bytes32 type on Ganache, providing a permanent, tamper-proof audit trail.
  • Dual-Checks: Separate verification steps guarantee that file content changes trigger a Tampered state, while signature mismatches trigger a Forged state.
